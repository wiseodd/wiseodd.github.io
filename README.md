# wiseodd.github.io

This repo exists so that GitHub Pages sends a 301 from every wiseodd.github.io URL to the same path on [agustinus.kristia.de](https://agustinus.kristia.de). The `CNAME` file does the work, so keep it and don't delete the repo, or old links to the blog will return 404 again.

Run `./check.sh` to confirm the redirects still work.
